# AYLLU

**Criamos juntos, aunque estemos lejos.**

AYLLU es una plataforma de acompañamiento en la crianza para abuelos y abuelas que cuidan a sus nietos mientras los padres trabajan en otra región del Perú. Permite registrar lo que pasa con el menor (también por voz), que el padre o la madre responda en su propio horario y que los acuerdos de la familia queden por escrito.

Proyecto final del curso **HCI for UX Design (1ASI0784)**, Universidad Peruana de Ciencias Aplicadas, ciclo 2026-20.

## Estructura

```
assets/   imágenes, íconos, fuentes y videos
css/      styles.css (tokens de diseño arriba del todo)
js/       main.js (rutas, estado y preferencias)
pages/    index.html (landing) y app.html (demo funcional)
docs/     contexto, identidad visual, DESIGN.md y arquitectura
```

Tecnologías: HTML, CSS y JavaScript, sin frameworks ni servidor. Los datos de la demo se guardan en el navegador (`localStorage`).

## Cómo verlo en local

Abra la carpeta con un servidor local (por ejemplo, la extensión Live Server de VS Code). El micrófono de las notas de voz solo funciona en `localhost` o HTTPS, no al abrir el archivo con doble clic.
